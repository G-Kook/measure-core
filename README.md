# MODULE DESCRIPTION

**gk/gkstr**<br>
Fixed-sized string type for easy use of strings.<br>

**gk/gkio**<br>
Data export, logging functionalities.<br>

**gk/gkdat**<br>
Simple 3-dimensional data handeling tool.<br>

**gk/gktml**<br>
Pad ID - pin ID mapping system with tags.<br>

**device/device_base**<br>
Base algorithms for measurements.

**device/gen10**(or gen11)<br>
Device configuration for each product.
