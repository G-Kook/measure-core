c library for core functionalities in device measurement, such as vnand, dram, etc.<br>
Copyright 2026, Geon Kook

[ MODULE DESCRIPTION ]<br>
** gk/gkstr: fixed-sized string type for easy use of strings.<br>
** gk/gkio: data export, logging functionalities.<br>
** gk/gkdat: simple 3-dimensional data handeling tool.<br>
** gk/gktml: pad ID - pin ID mapping system with tags.<br>
** device/device_base: base algorithms for measurements.<br>
** device/gen10 or gen11: device configuration for each product.
